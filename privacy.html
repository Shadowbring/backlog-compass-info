Backlog Compass Privacy Notice

Last updated — 2026-10-12

Who this is for

Backlog Compass is a personal household application maintained for the owner and invited household members. These pages describe its intended handling of data. Live Google Drive backup and recovery behavior has not yet completed operational qualification.

Application information

The application stores household account and session information, game-library and platform details, preferences, decisions, feedback, shared selections, and Evidence records used to document observations and decisions. Some of this information is personal. An encrypted backup can contain this application data, including private gaming information and Evidence; encryption does not mean that the backup contains no personal data.

Household members control their own information and choose what to share for shared recommendations. Ordinary application administration is designed not to grant access to another member's private gaming data. Trusted recovery, database, and infrastructure operators remain part of the household's operational trust boundary and may have capabilities beyond ordinary application administration.

Google Drive backups

The intended Drive integration stores and restores encrypted Backlog Compass snapshots and the metadata needed to manage those snapshots. The application is designed to use a dedicated Backlog Compass folder and the Google drive.file authorization scope, which is intended for files created or opened by this application. It is not intended to read or manage unrelated Drive files. The exact OAuth consent configuration, folder behavior, and upload/list/download/prune compatibility with that scope remain to be verified with Google before live use; no live capability is claimed here.

The backup process encrypts a database snapshot before upload. The private recovery key is not part of the uploaded snapshot; it is intended to be held off-laptop, separately from Drive and outside the normal application and backup processes. Actual off-laptop custody and complete recovery have not yet passed live operational qualification. The planned retention target is the latest 14 verified daily snapshots and 8 verified weekly snapshots. These are snapshot counts, not guaranteed calendar coverage; daily and weekly sets can overlap, and missed or failed runs can leave gaps. The currently verified artifact is always retained. Pruning of older verified artifacts occurs only after a new upload has been downloaded and its checksum verified; a failed or unverified upload does not trigger pruning. Unknown or unverified Drive files are left alone. Scheduled backups and full recovery have not yet passed live qualification.

You can revoke the application's Google account access using Google's account security controls. Revocation prevents future authorized Drive operations until access is restored; it does not itself delete backup files already stored in Drive. You can delete backups from the dedicated folder using Google Drive. Deleting a file can reduce recovery options, and separate recovery records or copies may remain outside Drive. The application cannot promise deletion of copies retained by Google or by a person who separately copied a backup.

Use and sharing of Google data

Google account data and Drive file content are used only for the backup and restore functions described above. They are not intended for advertising, sale, or training general-purpose AI or machine-learning models. If Google user data is accessed, its use and transfer will adhere to the Google API Services User Data Policy, including its Limited Use requirements. This commitment describes the intended handling of Google data; it is not evidence that OAuth publication or live operational qualification has been completed.

Hosting and network records

The application source and household data are private. These informational pages may be published separately as public static pages on GitHub Pages so Google can review the app's privacy and terms information. Publishing these pages does not publish the application source or household data. GitHub may process and log visitors' IP addresses and request information as part of hosting and security operations. Google Drive stores the encrypted backup files and associated backup metadata; Google processes them as the storage provider. The owner must review each provider's current terms and privacy practices before publication or use.
