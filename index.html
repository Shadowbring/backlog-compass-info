Backlog Compass

Last updated — 2026-10-12

Backlog Compass is a personal application for managing a household game backlog and related decisions. It is intended for use by the owner and invited household members. It is not a public service or a product offered to the general public.

Google Drive is intended only as a destination for encrypted Backlog Compass backup snapshots and the app's associated backup metadata. The application does not need access to a user's general Drive files for this purpose. The planned Google authorization is limited to files created or opened by this application (drive.file); the exact consent configuration and the ability to create and use its dedicated backup folder with that scope still need live verification.

Backups are encrypted before upload. Their contents can include personal game-library, household account, decision, and Evidence data. The recovery key is intended to be held off-laptop, separately from Google Drive and outside the normal application and backup processes. Actual off-laptop custody and complete recovery have not yet passed live operational qualification. Backup setup, OAuth renewal, and scheduled uploads also remain unqualified.

Read the Privacy Notice to learn what the application and its backup process are designed to handle. The Terms describe the intended personal-use arrangement.
